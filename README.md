# Trabalho-design-profissional

Tranca o curso.

Caio — Estrutura e Gerenciamento de Produtos
Responsável pelo desenvolvimento da estrutura de armazenamento dos produtos, utilizando listas e dicionários em Python. Implementou as funcionalidades de cadastro, busca e consulta do estoque, incluindo validações para evitar registros duplicados e entradas inválidas.

David — Controle de Entrada e Saída do Estoque
Responsável pelo desenvolvimento das funcionalidades de movimentação do estoque, permitindo adicionar e retirar quantidades dos produtos cadastrados. Implementou validações para impedir retiradas superiores à quantidade disponível e garantir a integridade dos dados.

João — Pesquisa, Exclusão e Interface do Sistema
Responsável pela implementação das funcionalidades de pesquisa e exclusão de produtos, além do desenvolvimento do menu interativo. Organizou a navegação entre as funcionalidades do sistema, utilizando estruturas condicionais e laços de repetição para facilitar a interação com o usuário.
